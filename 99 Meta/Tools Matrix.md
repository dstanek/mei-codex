## Observations

**Six active inboxes.** Evernote, Nozbe, Pocket, Medium, Substack, and Readwise each accumulate material that needs draining. That's six queues to process on a weekly review, and it's the strongest argument in this table for consolidating — every extra inbox is another place things go to be forgotten.

**Three tools marked for migration have no migration date.** Trello, OneNote, and Notion are all `Active: FALSE` with a note to move data, but nothing schedules that. Data sitting in a tool you've stopped opening is the highest-risk data you own.

**The browser rows describe a job that's now done.** *"Migrate stale tabs to a note; open tabs are for active work"* — that's exactly the OneTab cleanup completed 2026-08-05. See the disposition table in [[Watch & Read Queue]]. Worth deciding whether the same rule should apply going forward, so a new 72-link dump doesn't accumulate.

## Where this matrix is now out of date

Flagging these rather than silently correcting them — the matrix reflects a moment that has passed.

- **Obsidian is marked as having no inbox**, but this vault has `00 Inbox/` with roughly 90 notes in it. That's arguably your busiest capture point, so the count above is really *seven*.
- **Nozbe is listed; Todoist is absent.** [[Conventions]] is built entirely around Todoist — projects, domains, next actions, Someday/Maybe. Either the matrix predates that move, or Nozbe is a leftover row. If Todoist replaced Nozbe, Todoist should be here and Nozbe should be in the retiring table.
- **Pocket shut down in 2025.** If anything was saved there, it's worth confirming it was exported.

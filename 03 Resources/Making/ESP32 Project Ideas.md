## Graduating an idea

When you commit to one:

1. **Todoist** — create the project under the `Personal` parent, then add a due-dated next action.
2. **Obsidian** *(optional)* — `01 Projects/{Short Name}/{Short Name}.md` from the `Project.md` template, with the Todoist URL in `todoist:`.
3. Replace the row here with a link to the project so the list stays candidates-only.

Already graduated: [[Garage Door Automation]], [[Water Leak Detection]], [[Home Assistant]].

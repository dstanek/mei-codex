Chain-of-Thought exploitation
: manipulates AI reasoning for malicious goals (prompt injection for steering)

Goal hijacking/objective drift
: causes AI to deviate from its intended purposes using adversarial inputs or flawed training

Feedback loop exploitation
: repeatedly injecting biased or harmful data affecting learning

Prompt or policy override
: try to bypass safety filters using layered prompts, obfuscated language, or indirect requests that trick the model into ignoring restrictions

Resource abuse and denial of service
: overwhelm AI systems and degrade performance using lots of API call or computationally intensive tasks

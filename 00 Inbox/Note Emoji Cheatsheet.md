# Note Emoji Cheatsheet

## 📖 **General Notes**

- `:book:` → 📖 Book / source
- `:file-text:` → 📄 Document / text page
- `:notebook:` → 📒 Notebook
- `:sticky-note:` → 🗒️ Note, reminder

## ✍️ **Highlights & Quotes**

- `:quote:` → ❝ Quotation
- `:highlighter:` → 🖍 Highlighted passage
- `:pen-tool:` → ✍ Annotation / margin note
- `:bookmark:` → 🔖 Important page
    
## 💡 **Insights & Takeaways**

- `:lightbulb:` → 💡 Idea / insight
- `:target:` → 🎯 Key point / focus
- `:key:` → 🔑 Key takeaway
- `:check-circle:` → ✅ Actionable conclusion
- `:brain:` → 🧠 Knowledge / reflection
    
## ❓ **Questions & Follow-Ups**

- `:help-circle:` → ❓ Open question
- `:search:` → 🔍 Need to research
- `:link:` → 🔗 Related connection
- `:compass:` → 🧭 Explore further

## ✅ **Tasks & Actions**

- `:check-square:` → ☑ To-do
- `:list-todo:` → 📝 Checklist
- `:calendar:` → 📅 Deadline / date
- `:flag:` → 🚩 Priority
    
## 📊 **Evaluation & Reviews**

- `:star:` → ⭐ Favorite part / rating
- `:thumbs-up:` → 👍 Approval
- `:thumbs-down:` → 👎 Criticism
- `:scale:` → ⚖ Balance / pros & cons
